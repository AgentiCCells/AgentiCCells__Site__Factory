## The work, from public sources (each read 2026-11-16)

  - **Hack the Agent** (https://agent-defense-arena.lovable.app/): a live, multiplayer game that teaches prompt injection. A host opens a session, the audience joins by QR code on their phones, and players try to trick five fictional agents, each better defended than the last (system prompt only; rules; indirect injection through an inbox; a refund desk with server-side checks; a hardened agent with an instruction hierarchy, tool allowlist, server-side authorisation and output filter). Traces of every tool call, a live request budget, rate limits, leaderboards and a presentation mode. The review's three live attempts were all refused, and the output filter caught the last practice attempt.
  - **ReachCheck** (https://reach-check-agent.lovable.app/): checks an agent's configuration against what its owner authorised, entirely in the browser.
